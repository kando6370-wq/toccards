# 项目文档

文档按发布版本归档。`v1.0.0` 保存已发布实现基线和最初 PRD，`v1.1.0` 只记录下一版本相对基线的增量。

## 阅读入口

- [`releases/v1.0.0/`](releases/v1.0.0/)：当前已发布基线，包含产品原件、业务流程、架构、数据/API 和管理后台文档。
- [`releases/v1.1.0/`](releases/v1.1.0/)：v1.1.0 的需求、契约变化、迁移与发布标准。

## 目录规则

```text
docs/
└── releases/
    ├── v1.0.0/
    │   ├── 00-product/       # 原始 PRD，只读保留
    │   ├── 01-flows/         # 已发布业务流程与状态
    │   ├── 02-architecture/  # 已发布架构与技术边界
    │   ├── 03-data-api/      # 已发布数据与 API 契约
    │   └── 04-admin/         # 已发布管理后台能力
    └── v1.1.0/               # 相对 v1.0.0 的增量文档
```

- `00-product` 中的 PRD 是历史需求原件，不随实现修订。
- `01-flows` 至 `04-admin` 描述对应版本实际代码、迁移和运行配置。
- 新版本只记录变化；未变化的能力继续引用上一版本。
- 不提交任务日志、临时审计、交接资料、测试失败截图或原始设计导出物。
