# Admin 启动会话校验

## 问题与根因（2026-11-12）

Admin 页面启动时曾直接把 `localStorage` 中的会话当作有效状态，先挂载 `AdminShell`，再等待受保护接口返回 401。过期或已撤销的会话因此会短暂显示内部页面，随后才切换到登录页。

## 当前行为

- 没有持久会话时直接显示登录页。
- 有持久会话时先调用 `/api/v1/admin/auth/refresh`；正常成功分支使用新的 `access_token` 挂载 `AdminShell`。
- 刷新返回可解析的 API 错误且 HTTP 状态为 401／403，或成功返回的数据对象中的 `access_token` 为空或非字符串时，清除本地会话并显示登录页。
- 网络或服务端非认证错误保留原会话，避免短暂服务故障强制退出；后续受保护请求仍沿用既有 401 失效处理。

认证校验等待期间显示加载状态，不挂载后台业务页面。非认证异常（含响应 JSON 解析失败）仍会结束等待并使用旧会话挂载后台，因此不能将当前实现描述为“任何校验失败都不展示内部页”。该修复只涉及 Admin 前端启动状态和既有刷新接口，不改变 API、数据库、权限规则或 Flutter 行为。
