## 本地验收

- 官网 232 项和目录只读服务 39 项测试通过。官网类型检查、依赖方向和 diff 格式检查通过。使用 Node 22.23.1 和 pnpm 11.28.10。仓库首选 Node 22.23.4，安装和命令输出了版本提示。
- Pages 构建及普通 Workers 构建均生成 151 条路由，保留 46 个旧内容来源。Workers 生产配置的 dry-run 使用普通构建通过。Pages 专用的 `_worker.js` 由 Pages 构建打包。
- 本地用 HTTP 检查 16 个新页面各自的 canonical、H1 和 70 个正文内链。390 像素窗口检查首页、价格方法、竞品中心和识别方法，页面宽度均为 390 像素。
- App 范围为商店文案检查，未改 Flutter 功能。商店预览素材仍需按两端可用版本实拍。真实用户评价和独立评测仍由真实用户与评测方产生。
