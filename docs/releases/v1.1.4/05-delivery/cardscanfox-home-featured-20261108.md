# 首页卡牌主题更新

用户要求官网首页展示近期卡牌主题，先查自身卡库，缺少时可检索网络补充。本轮沿用当前浅色/黄绿色设计，聚焦首页，不恢复已停止的 Trends 扫描。

## 当前证据与选取

2026-11-08 正式只读接口回读：ME: 30th Celebration 有 161 张公开单卡，Classic Collection 有 30 张；Delta Reign 仍没有可公开单卡。仅展示已确认卡牌的图、编号、语言/工艺及价格日期：Charizard 4/102（714372）、Pikachu ex 150/128（712954）、Mew ex 152/128（717605）、Gengar ex 154/128（717610）、Ancient Origins M Rayquaza EX 98/98（101520）、Roaring Skies M Rayquaza EX 105/108（98141）。前四张是周年系列，后两张为旧版印次，不能作为 Delta Reign 卡或价格。

首页把首屏三张卡、对应价格卡片和六张卡牌浏览区改为上述编辑选取。每张图片、名字、金额与详情地址来自同一条数据库记录；金额沿用已发布价格和观测日期，不写在配置中，不用固定样本价代替。编辑顺序与目录排序独立，不意味着这些单卡分别具有某一搜索涨幅或价格涨幅排名。

新增周年、Mega Rayquaza、Delta Reign 三个主题入口。周年进入真实系列，Rayquaza 进入具体印次指南，Delta Reign 进入已有发行指南，附 UPC 入口。原产品文案、功能流程、原有正文与旧地址继续保留。首页 Description 说明产品能力和这些卡牌主题，Title 保持主产品意图。

## 数据读取与边界

共享公开配置位于 `packages/website-content/data/home-featured.json`。仅新 website-service 的 homepage page-data 使用最多 8 个绑定 ID 在原目录 SQL 中读取，单次查询后按编辑顺序排列；沿用启用卡种、实体单卡、有图和 RAW 价格边界。普通目录、卡牌详情、排序与原 App/API/Admin/Flutter/旧官网代码不改。不新增数据库、账号、schema 或业务写入。新服务依旧复用既有数据库连接资源，不能据此宣称完全性能隔离。

缺失/下架/无图的精选记录跳过，不拿目录前几张或样本填补。新模块的空状态提供目录与指南去向。首页主题是有证据的编辑选择，不作为全站搜索排行榜。

核对了 Pokémon 官方 Delta Reign 新闻与媒体使用规范；没有将缺失卡图、未核对的网页图片或旧印次图片冒充新卡。官网现有卡图已足够满足首页主题展示，未下载或导入外部卡牌记录。未修改正式数据库。
