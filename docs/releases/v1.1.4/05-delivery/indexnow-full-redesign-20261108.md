# 改版 URL 全量通知

用户于 2026-11-08 要求改版 URL 全部提交。本轮范围是正式发布清单与正式 sitemap 中可索引的公开页面，不宣称遍历了数据库中数百万个尚未纳入本次发现清单的动态详情。

## 清单补齐

原正式地图为 69 个栏目/文章页与 1,063 个单卡页，共 1,132。发布清单 114 个静态条目中，排除 Saved 后有 42 个地址尚未列入地图。

使用 indexnow-submit 的 inspectPage 按约 2.5 秒一次的节奏检查这 42 个正式 URL，避免集中触发只读服务：其中 10 个系列页和 18 个单卡页为 HTTP 200、自指 canonical、无 noindex；12 个为 404，2 个带 noindex，后 14 个不纳入通知。检查结果在忽略目录 `.local/indexnow-full/release-route-audit.json`。

新增 10 个系列地址到 site sitemap、18 个单卡地址到 card sitemap，保留既有所有地址和顺序。新清单共 79 个栏目/文章与 1,081 个单卡，合计 1,160。手动卡牌地图生成器读取已验证发布卡牌 ID，避免下次生成丢失这些首次详情入口。

## 提交与边界

先完成地图修改和文档，再做受影响地图/SEO/原文保留检查与打包，发布后回读正式清单和版本。IndexNow 官方批量 POST 支持每批最多 10,000 URL，本次将已验证 key 和全部 1,160 个正式同域地址组成一个请求，不因本地内容 hash 未变化而跳过本次全量通知。

批量提交前校验 sitemap、同域、无查询参数/fragment、robots 放行、key 文件精确一致，并抽查正式内容。此次没有额外逐条重新读取原有 1,063 个单卡详情；其提交资格沿用已发布目录检查及正式 sitemap，新增遗漏地址则逐条做了 HTTP 检查。不能把批量 HTTP 200 说成每个页面均已抓取或收录。

保留完整 URL 文件、HTTP 接收回执和校验方式，只有接口返回 200/202 后才更新通知状态。没有设置 Cron，不修改 App/API/Admin/Flutter、数据库或安全配置。
