## 3. 背景、问题与目标

### 3.1 背景

TCG Card 已有完整 Subscription Page 与功能卡点 Subscription Paywall Modal。现有 App PRD 固定了购买、Restore、权益刷新、Terms、Privacy 和来源返回规则，但缺少一份独立、可实施的后台展示配置规范。

订阅配置需要直接读取 Apple 已创建商品，支持多个不生效配置、页面展示 SKU 排序、试用 SKU 对应关系和配置级生效开关。无需在本系统重复维护一份商品记录；本 PRD 同时补齐客户端读取、试用选择联动、兜底和后台异常规则。

### 3.2 要解决的问题

1. 产品配置缺少统一规则管理订阅页与订阅大弹窗的展示组合。
2. 先登记后台商品再配置页面会重复维护 Product ID、类型、周期和试用信息，并产生与 Apple 商品不一致的风险。
3. 商品免费试用属性、独立页面展示和同位置试用切换是三个不同概念，需要明确各自作用范围。
4. 保存配置、打开生效开关和客户端读取配置是三个不同动作，需要避免状态误判。
5. 商品、配置或试用信息失败时，客户端不得生成虚假价格或错误购买目标。

### 3.3 目标

- 支持后台直接读取当前 App 的 Apple 订阅商品和 Lifetime 商品供产品选择，不在本系统创建或修改 Apple 商品。
- 支持订阅页、订阅大弹窗分别保存多组配置，并分别最多启用一组。
- 支持页面展示 SKU 的字段、排序、默认项和价格展示方式，包括独立展示带免费试用的商品。
- 支持多个普通付费 SKU 分别建立到同周期试用 SKU 的安全对应关系。
- 让客户端在配置失败、商品失败或试用不可用时有明确、可验证的降级行为。
- 保证购买目标 Product ID 与当前界面展示内容始终一致。

### 3.4 验收目标

以下为发布门槛，不新增业务埋点要求：

- 同一页面类型同时生效配置数始终小于或等于 1。
- 后台不能保存重复 Product ID、缺少默认 SKU 或无效试用关系。
- 试用购买提交时，展示 SKU、试用 SKU 与实际购买 Product ID 一致率为 100%。
- 配置获取失败、配置关闭和 Apple 商品加载失败的兜底用例全部通过。
- 保存或生效切换失败后，不丢失用户输入，不误报成功，不产生重复记录。

## 6. 全局规则与数据来源

### 6.1 核心术语

| 术语 | 定义 |
| --- | --- |
| Apple 商品 | Apple 后台中属于当前 App 的订阅商品或 Lifetime 一次性购买商品；本系统只读取和引用 |
| 项目指定订阅组 | 项目接入时确定、用于读取本期可配置订阅商品的唯一 Apple 订阅组；不作为产品填写或选择的字段，也不能代替具体 Product ID |
| 订阅等级 | Apple 订阅组内商品的等级信息；建立普通付费 SKU → 试用 SKU 关系时用于校验两者等级一致 |
| 苹果后台参考名称 | Apple 商品中供后台辨认的参考名称；不直接作为 App 页面展示文案 |
| 页面展示 SKU | 作为独立方案卡片展示和选择的 Product ID；可以是不带试用的订阅商品、带免费试用的订阅商品或一次性商品 |
| 普通付费 SKU | Apple 商品信息中不包含免费试用的订阅商品；仅在建立试用切换关系时作为关系源 |
| 试用 SKU | Apple 商品信息中包含免费试用的订阅商品；既可以作为独立页面展示 SKU，也可以作为试用切换关系目标 |
| 独立试用 SKU | 直接加入页面展示 SKU 列表的试用 SKU，使用自身卡片配置和自身 Product ID 购买 |
| 试用切换功能 | 在同一页面展示卡片位置，将普通付费 SKU 的购买目标与文案切换为关联试用 SKU 的可选功能 |
| 页面类型 | `订阅页` 或 `订阅大弹窗` |
| 生效配置 | 某页面类型当前供客户端读取的唯一启用配置 |
| 客户端兜底配置 | 由对应页面最新确认的 UI 稿确定并随客户端提供，不依赖本后台本次成功返回 |
| 当前页面配置快照 | 客户端进入 Page/Modal 后，本次页面实例使用的配置副本 |

### 6.2 数据来源与信任边界

| 数据 | 来源 | 规则 |
| --- | --- | --- |
| Product ID | 后台直接读取 Apple 商品 | 产品通过商品下拉选择，不手动录入或解析命名字符串 |
| 项目指定订阅组 ID | 项目接入配置 | 由项目接入时确定；不在页面展示或由产品填写、选择；未知时不得使用原型示例 ID 冒充真实值 |
| 苹果后台参考名称 | 后台直接读取 Apple 商品 | 与 Product ID 一起用于后台辨认；缺失时只显示 Product ID；不替代 App 页面展示文案 |
| 商品类型、周期、所属订阅组和订阅等级 | 后台直接读取 Apple 商品 | 用于商品范围、展示和关系校验；产品不重复填写，所属订阅组不作为可编辑字段 |
| 免费试用信息 | 后台直接读取 Apple 商品 | 按优惠类型、地区及生效时间识别；用于筛选关系，不证明当前用户有资格；本期免费试用限定有效的介绍性免费优惠，不混用优惠码或促销优惠 |
| 展示文案、顺序、默认项、生效状态 | 产品配置 | 配置无效时使用对应客户端兜底 |
| 实际价格、币种、试用时长、续订信息 | 客户端读取 Apple 商品信息 | 后台不得手动填写或用示例值替代 |
| 收入事件 Product ID、实际支付金额、币种、交易标识 | Apple 确认成功的实际交易 | 用于事件匹配、价值上报和幂等；不得使用页面展示名称、试用开关状态、周均折算价、后台示例价或预计未来续订金额替代 |
| 试用资格 | 客户端结合 Apple 相关能力判断 | 区分有资格、无资格、未知；同时约束关联切换和独立 SKU 的免费承诺，后台标记不能替代判断 |
| Premium 权益结果 | 既有 verified transaction / entitlement 机制 | 本 PRD 不改变权益真值来源 |

### 6.3 后台写入、超时与结果未知

本节的 15+15 秒只适用于后台配置新增、保存和生效切换。客户端配置和 Product Loading 使用第 6.6 节的单次 15 秒总预算；Apple Purchase 与 Restore 不套用后台写入计时。

1. 写入请求进行中，禁用重复提交和会与本次请求冲突的相关操作。
2. 明确成功后按服务端结果更新页面。
3. 明确失败且服务端确认未写入时，保留输入或原记录，恢复适用操作。
4. 写入请求达到 15 秒仍未确认结果时，进入状态核对；不得直接认定失败，也不得立即允许重复提交。
5. 状态核对最多再等待 15 秒，期间相关写入操作继续禁用。
6. 状态核对成功后按实际结果更新页面；已经成功的操作不得重复执行。
7. 状态核对失败或超时后结束等待，保留输入，允许离开，并提示：`暂时无法确认操作结果，请稍后重试`。
8. 用户之后再次提交相关操作前，客户端或后台前端必须先核对原请求状态，并结合幂等保护避免重复配置或重复生效切换。
9. 原写入请求的迟到响应不得覆盖更新后的页面状态或已经确认的操作结果。
10. 生效替换必须是同页面类型内的原子操作，不允许短暂或最终出现两组同时生效。

### 6.4 配置快照与刷新

1. 后台保存成功不代表已打开的客户端页面立即变化。
2. 客户端在下次进入对应 Subscription Page 或 Paywall Modal 时，按既有读取机制取得最新生效配置。
3. 当前页面实例从展示开始到关闭或购买流程结束，使用同一配置快照。
4. 后台期间发生修改时，当前页面不得突然切换 SKU、默认项、购买目标或文案。
5. 本期不新增实时推送、长连接、缓存刷新或页面内热更新机制。

### 6.5 统一字符上限

普通状态与试用状态的同类字段使用相同录入上限。前端字符计数、前端校验、服务端校验和验收用例必须一致。

| 字段 | 最大字符数 |
| --- | --- |
| 配置名称 | 100 |
| 普通/试用商品展示名称 | 100 |
| 组级订阅按钮兜底文案 | 100 |
| 页面展示 SKU / 关联试用 SKU 订阅按钮文案 | 100 |
| 试用开关文案 | 100 |
| 名称下方副文案 | 300 |
| 右上角角标文案 | 100 |
| 价格下方说明文案 | 200 |
| 自定义购买按钮正上方说明文案 | 500 |

以上为产品配置文案的录入上限，不要求新增复杂排版能力。Product ID 和苹果后台参考名称来自 Apple，不属于手工录入文案。

组级、页面 SKU、关联试用 SKU 三处按钮文案仅支持纯文本，不允许任何 `{` 或 `}` 字符；`{price}` 也不得填入按钮。纯空白按空值回退，长度按原始输入的 UTF-16 代码单元计数，前后端保持一致。`{price}` 只在副文案、角标、价格下方说明和自定义按钮上方说明中展开；这些字段的其他完整占位符必须拒绝。关闭关联切换时，隐藏的旧试用文案按原规则保留，不参与客户端展示；重新开启时须完成纯文本及长度校验。

### 6.6 客户端加载与 Restore 时序

1. 本期 Page／Modal 自本次进入开始，配置读取、结构校验、StoreKit 商品加载及兜底商品加载共用 15 秒总预算。此项是相对当前源码默认 25 秒的明确变更。
2. 配置读取最多占用前 3 秒；无配置、失败或超时后立即锁定本地兜底。剩余时间供真实商品加载，进入兜底、自动重试均不重置总预算。
3. 有效远端配置下部分商品失败，只保留成功且计费信息完整的商品。若远端商品全部不可用，可在剩余预算内尝试本地兜底一次；不在远端和兜底之间循环切换。
4. 最多 3 次自动重试继续共享总预算，达到总 Deadline 即结束 Loading。用户主动重试开启新加载周期，但不重置同一页面的关闭按钮延迟，也不重新接受迟到远端配置。
5. 已可购买商品不因其他商品或试用资格未返回而无限等待；资格未知时按第 7.6.7 节提供准确的普通交易信息。
6. 本期不修改 Restore 的现有阶段和超时：当前部分请求／读取阶段为 25 秒，前置同步另有时序，不能将其描述为已实现的端到端 25 秒或 15 秒保证。保持入口、互斥、取消、结果和权益处理；统一 Restore 总 Deadline 如需调整，另行明确范围。

### 6.7 真实交易说明优先于营销文案

- 每张可购买卡片都必须突出展示当前实际商品的完整正常扣费金额及真实计费周期；一次性商品明确一次性金额。周均值只作辅助参考。
- 当前选中商品在购买按钮附近必须有固定真实交易摘要。适用免费试用时，摘要包含真实试用期限、试用结束后金额与周期；无资格时不承诺免费，资格未知时仅说明标准价格和优惠待确认。
- 运营自定义说明可以为空，但不能移除、替换或弱化上述交易信息。自动说明与固定摘要内容相同的时候只展示一次。
- 金额、币种、真实周期或适用试用必要信息缺失时，该状态不得发起购买。普通周期信息完整而独立试用资格未知时，可按第 7.6.7 节的中性展示继续购买。
- 资格安全展示优先于运营按钮及卡片文案。资格未知不是“无资格”，也不得被当作商品加载失败或擅自改换 Product ID。

## 7. 解决方案

### 7.1 后台信息架构

一级菜单：`订阅配置`

进入一级菜单后直接显示`订阅页配置`。本期取消独立`商品列表`页面，不保留商品新增、编辑、删除或手动登记入口。

`订阅页配置`同时管理两种页面类型：

- 订阅页（Subscription Page）
- 订阅大弹窗（Subscription Paywall Modal）

两种页面类型的配置、试用设置和生效状态相互独立。

#### 7.1.1 对现有 App PRD 的覆盖范围

本增量覆盖 [TCG_Card_App_v1.1_PRD.md](../../v1.1.0/00-product/TCG_Card_App_v1.1_PRD.md) 中“Subscription Page 与 Paywall Modal 使用相同 Plans / Products、默认选中项”的旧规则：

- 生效后台配置有效时，两种页面类型分别使用各自的页面展示 SKU 组合、顺序、默认项、展示文案和试用切换设置。
- 两种页面类型不再要求商品组合和默认项相同。
- 页面标题、Premium Benefits、Restore、Terms、Privacy、购买结果和来源返回仍沿用现有 App PRD，不被本增量覆盖。
- 后台配置不可用时，使用对应页面最新确认 UI 稿确定的客户端兜底；UI 稿未注明的真实 Product ID 按第 8.2 节核对。

### 7.2 Apple 商品读取与选择

#### 7.2.1 商品来源与范围

1. 商品的创建、修改、上下架和试用优惠管理在 Apple 后台完成。
2. 本后台不维护独立商品记录；项目接入时确定一个指定订阅组，配置页只读取该组内订阅商品，并另行读取本次可配置的一次性购买商品。
3. 项目指定订阅组 ID 不作为产品填写或选择的字段，页面不提供订阅组下拉。真实 ID 未确认时必须列为研发实施核对，不得使用原型示例 ID、商品名称或 Product ID 字符串猜测。
4. 可选范围必须同时覆盖项目指定订阅组内的自动续期订阅商品和 Lifetime 等一次性购买商品，不能因为一次性购买不属于订阅组而遗漏。
5. Product ID、苹果后台商品参考名称、商品类型、计费周期、订阅等级和免费试用信息均从 Apple 商品读取，产品不重复填写或人工标记。
6. 页面展示名称、副文案、角标、价格说明、按钮文案和按钮上方说明仍由产品按本 PRD 配置，不得用苹果后台参考名称自动替代。
7. 后台不提供 Apple 商品创建、编辑、删除、价格输入、币种输入、试用天数输入或试用优惠创建入口。
8. Apple 目录中存在商品不代表系统已支持。未完成服务端商品白名单、active 权益映射和适用范围核验的商品，可保存在不生效配置中准备，必须显示未接入原因，不能启用；编辑生效配置并保存时执行同样的准入检查。
9. 一次性范围仅包括本项目已确认授予永久 Premium 的非消耗型商品，不把消耗型或任意一次性商品直接视为 Lifetime。
10. 展示 SKU 集合与长期受支持权益商品集合分离。移除卡片、关闭配置、商品停卖均不得自动撤销历史验单、通知和恢复支持。

#### 7.2.2 商品类型与下拉展示

每张页面展示 SKU 卡片按`商品类型 → Product ID`选择，最终配置必须关联具体 Product ID。

| 字段/内容 | 展示与交互规则 |
| --- | --- |
| 商品类型 | 单选：`订阅` / `一次性购买`；新增 SKU 默认选择`订阅` |
| Product ID | 使用整行宽度的下拉框；订阅模式直接显示项目指定订阅组内商品，一次性购买模式显示当前 App 本次可配置的一次性购买商品；展开后直接滚动选择 |
| Product ID 选项及选中状态 | `Product ID · 苹果后台参考名称`；参考名称缺失时只显示 Product ID；免费试用商品可显示`带免费试用`辅助标识 |

页面展示 SKU 和关联试用 SKU 均通过整行 Product ID 下拉直接滚动选择。订阅模式直接读取项目指定订阅组中的不带试用和带免费试用商品，不提供订阅组选择。一次性购买模式只展示本次允许配置的一次性购买商品，例如 Lifetime。`一次性购买`是交易类型，不是 App 营销名称；卡片上的`Lifetime`等名称继续由产品配置。

格式示例：

```text
com.tcg.premium.weekly · Premium 周订阅
```

以上只说明 Product ID 选项格式，不代表真实线上商品。苹果后台参考名称只用于后台辨认，不直接作为 App 页面营销文案。

#### 7.2.3 切换与编辑恢复

1. 切换商品类型时，立即清空当前 Product ID 和该卡片原试用目标；切换到一次性购买时不显示试用关联入口。
2. 类型切换只清理商品选择和关系标识；已填写的商品展示名称、副文案、角标、价格说明、按钮上方说明等营销文案继续保留。
3. 所有变更只作用于当前编辑副本；取消或确认放弃后不修改最近一次成功保存的配置。
4. 编辑已有 SKU 时，根据已保存 Product ID 对应的 Apple 商品信息回显商品类型和 Product ID，不要求产品重新选择。
5. 独立试用 SKU 通过`订阅 → Product ID`直接加入页面展示列表，不要求开启试用切换功能。
6. 关联试用 SKU 从同一个项目指定订阅组中选择，不额外提供商品类型或订阅组选择；继续执行第 7.6.2 节配对规则。

#### 7.2.4 加载、空状态与刷新

项目指定订阅组内商品和一次性购买商品分别在对应选择区域呈现状态：

| 状态 | 产品行为 |
| --- | --- |
| 读取中 | 当前商品选择区域显示加载并暂不可选择；页面内文案编辑、排序等无关操作不被阻塞 |
| 读取成功且有数据 | 显示当前商品类型对应的 Product ID 下拉选项，展开后可直接滚动选择 |
| 读取成功但无数据 | 明确提示指定订阅组或一次性购买范围没有可配置商品 |
| 读取失败 | 显示读取失败和重试；不得显示成“没有商品” |

1. 指定订阅组内商品或一次性购买商品读取失败，只影响当前商品选择区域，并保留其他已填写内容。
2. 切换商品类型后，旧类型的迟到结果必须丢弃，不得覆盖当前下拉选项或恢复已清理选择。
3. 编辑已有配置时，读取失败不得清空已经保存的 Product ID、页面展示文案、排序、默认项、试用关系或说明配置；读取恢复前，不把未知状态解释为商品已删除。
4. 刷新 Apple 商品信息只更新选择时使用的参考名称、类型、周期、等级和试用信息，不覆盖产品配置的展示文案、排序、默认项或试用替换文案。
5. 刷新后商品信息导致既有关系不再满足条件时，按试用关系校验提示产品调整；不得静默改选其他 Product ID。

#### 7.2.5 配置内添加与移除

1. `添加 SKU`只在当前页面配置中增加一个空商品位置。
2. 产品选择商品类型和具体 Product ID 后，再填写页面展示文案、设置排序和默认项。
3. `移除 SKU`只把该商品位置从当前配置中移除，不删除或修改 Apple 商品，也不影响已有购买、订阅、Lifetime 权益或订单。
4. 移除关联关系只影响当前配置中的试用切换；不改变 Apple 商品本身的试用信息。

### 7.3 订阅页配置列表

#### 7.3.1 列表字段

| 字段名称 | 展示内容 | 数据来源 | 联动规则 |
| --- | --- | --- | --- |
| 配置名称 | 产品配置名称 | 配置记录 | 用于区分多组不生效配置 |
| 页面类型 | 订阅页 / 订阅大弹窗 | 配置记录 | 两种类型分别管理 |
| 商品信息 | 按配置顺序展示页面展示 SKU Product ID | 页面展示 SKU 配置 | 带试用商品可以作为独立卡片出现 |
| 试用配置 | `试用切换未启用`或全部普通付费商品 → 试用商品关系摘要；关闭时如有保留关系则标记`未使用`；存在独立试用商品时附带数量 | 试用切换配置与页面展示 SKU 属性 | 按页面展示顺序列出所有关系；切换状态不代表独立试用商品不可用，也不代表用户资格 |
| 生效状态 | 生效 / 不生效开关 | 配置状态 | 同页面类型最多一组生效 |
| 更新时间 | 最近一次成功保存时间 | 服务端 | 保存失败不得更新 |
| 操作 | 编辑 | 配置记录 | 本期不增加复制、版本回滚或定时发布 |

#### 7.3.2 配置状态规则

1. 允许每种页面类型保存多组不生效配置。
2. 不增加草稿状态；记录只有生效/不生效。
3. 新增配置保存成功后默认不生效。
4. 保存只更新内容，不自动打开生效开关。
5. 编辑已生效配置并保存后，该配置保持生效；后续客户端读取更新后的内容。
6. 两种页面类型互不影响。
7. 已生效配置的页面类型只读，不允许在编辑表单中直接修改。
8. 确需修改页面类型时，先在列表关闭该配置的生效状态，再进入编辑修改。
9. 未生效配置可以修改页面类型，保存后仍为未生效；后续启用必须使用列表生效开关和既有替换确认流程。
10. 保存内容不得暗中改变订阅页与订阅大弹窗的生效归属。

#### 7.3.3 打开生效开关

| 场景 | 行为 |
| --- | --- |
| 同类型没有生效配置 | 直接确认开启目标配置 |
| 同类型已有其他生效配置 | 弹出替换确认，明确显示将关闭的旧配置和将开启的新配置 |
| 用户取消替换 | 不修改任何配置状态 |
| 用户确认替换 | 服务端原子关闭旧配置并开启新配置 |
| 切换失败 | 保持最后一次已确认状态，不允许两组同时生效 |
| 切换超时/结果未知 | 重新读取该页面类型实际生效配置后再反馈结果 |

#### 7.3.4 关闭生效开关

1. 允许关闭当前生效配置。
2. 关闭后该页面类型可以没有生效配置。
3. 客户端下次进入对应页面时使用对应兜底配置。
4. 关闭订阅页配置不影响订阅大弹窗，反之亦然。

### 7.4 配置新增与编辑

#### 7.4.1 配置级字段

| 字段名称 | 控件 | 必填 | 默认值 | 限制 | 数据来源 | 联动规则 |
| --- | --- | --- | --- | --- | --- | --- |
| 配置名称 | 单行文本 + 计数 | 是 | 空 | 最多 100 字符 | 产品配置 | 列表展示；不决定页面类型 |
| 页面类型 | 下拉框/只读值 | 是 | `请选择` | 订阅页 / 订阅大弹窗 | 产品配置 | 未生效时可修改；已生效时只读；决定独立生效域和客户端读取入口 |
| 启用试用切换开关 | 复选框 | 否 | 关闭 | 布尔值 | 产品配置 | 只控制同一位置的普通／关联试用切换；关闭时隐藏关系编辑，不等于配置停用；独立商品的免费承诺仍受自身资格约束 |
| 试用开关文案 | 单行文本 + 计数 | 条件必填 | 空 | 启用试用切换时必填；最多 100 字符 | 产品配置 | 切换功能关闭时保留但不展示、不参与试用完整性校验 |
| 组级订阅按钮兜底文案 | 单行文本 + 计数 | 否 | 空 | 最多 100 字符 | 产品配置 | 当前实际 SKU 的订阅按钮文案为空时使用；本字段也为空时使用客户端固定默认 `SUBSCRIBE`；不得覆盖已填写的 SKU 文案 |
| 关闭按钮延迟显示秒数 | 非负整数输入 | 是 | 0 | 单位秒；不设置业务时长上限 | 产品配置 | 自本次订阅页或订阅大弹窗进入时开始计时，经过配置秒数后显示关闭按钮；0 秒立即显示 |
| 生效状态 | 列表开关，不在编辑表单内 | - | 新增为关闭 | 同类型最多一个开启 | 配置状态 | 保存不改变该字段 |

#### 7.4.2 关闭按钮延迟规则

1. 字段必须为非负整数，单位为秒，默认值为 0。
2. 自本次订阅页或订阅大弹窗进入时开始计时，经过配置的秒数后显示关闭按钮；0 秒表示立即显示。
3. 订阅页与订阅大弹窗分别在各自本次进入时开始计时。
4. 不设置业务时长上限；客户端不得自行截断为 30 秒。
5. 同一页面内选择 SKU、切换试用或重试商品加载，不重新开始计时。
6. 商品加载最终失败或没有可购买商品时，立即提供关闭入口，不继续被长延迟阻塞。
7. 本字段只延迟关闭按钮显示，不新增系统返回或容器手势拦截；购买／恢复中的既有互斥和返回规则保持。配置到达较晚时按页面已进入的时长计算，不重新起算。

#### 7.4.3 固定内容

以下内容沿用现有 App 设计，不进入后台配置：

- 页面标题。
- Premium Benefits / 权益内容。
- Restore 入口及结果处理。
- Terms of Use。
- Privacy Policy。
- 购买成功后的权益发放与来源返回。

本期不增加客户端预览。

#### 7.4.4 新增配置

1. 点击`新增`进入与编辑相同的配置表单。
2. 配置级字段为空；关闭延迟默认 0；试用切换功能默认关闭。
3. 初始包含一张空白页面展示 SKU 卡片，不预填 Product ID 或营销文案；商品类型默认选择`订阅`。
4. 商品选择区按商品类型直接读取项目指定订阅组内商品或本次可配置的一次性购买商品；产品无需先进入其他页面登记商品，也不选择订阅组。
5. 试用切换关闭时不显示`关联试用 SKU`和替换文案；开启后才显示完整关联配置入口。
6. 保存前执行第 7.8 节校验。
7. 保存成功返回配置列表，并以`不生效`状态展示。
8. 保存失败或超时保留全部输入、SKU 顺序、默认项和试用文案。

#### 7.4.5 编辑配置

1. 打开时恢复最近一次成功保存的配置级字段、SKU 顺序、默认项、试用关系和文案，并按各 Product ID 回显商品类型与具体商品。
2. 试用切换开启时显示完整关系和替换文案；关闭时隐藏这些编辑控件，有保留关系时只显示未启用摘要和`解除试用关联`操作。
3. 编辑期间不改变线上生效内容。
4. 保存成功后返回列表并更新内容与时间。
5. 已生效配置保持原生效状态；未生效配置保持未生效。
6. 已生效配置的页面类型只读；其他允许编辑字段保存成功后保持生效，供后续新打开页面读取。
7. 如需修改已生效配置的页面类型，先返回列表关闭生效状态，再进入编辑。
8. 未生效配置可以修改页面类型，保存后仍为未生效。
9. 明确失败且服务端确认未写入时保留编辑输入，服务端旧版本继续有效；结果未知时按第 6.3 节核对，不得提前保证旧版本仍有效。
10. 已有配置兼容：保留原组级按钮文案和已有关联试用 SKU 按钮文案；其他页面展示 SKU 的新增按钮文案字段按空值恢复，继续通过组级兜底保持原有展示，不得在迁移时自动复制或改写。

#### 7.4.6 取消与关闭

1. 未修改时可以直接返回列表。
2. 存在未保存修改时，返回、取消或关闭必须显示放弃修改确认。
3. 取消确认后停留编辑页并保留输入。
4. 确认放弃后返回列表，丢弃本次未保存内容。

#### 7.5.2 页面展示卡片规则

1. 所有有效页面展示商品卡片同时展示各自名称、副文案、角标、价格和价格说明，不要求先选中。
2. 选填字段为空时，不展示该字段对应内容。后台配置生效时，价格下方只使用当前实际 SKU 的配置文案；该字段为空也不显示客户端按 StoreKit 周期生成的旧文案。仅未取得有效后台配置并进入客户端兜底时保留原周期文案。
3. 购买按钮正上方说明方式和内容随当前实际选中的 SKU 切换，其规则与订阅按钮内文案相互独立。
4. 每个页面展示 SKU 均可独立配置订阅按钮文案；普通订阅、独立试用 SKU 和一次性购买选中时使用各自字段。
5. 客户端试用切换开启时，只替换开启瞬间选中且具有有效关系的卡片展示内容、实际购买目标、关联试用 SKU 订阅按钮文案和按钮上方说明；其他已关联卡片仍保持基础 SKU 展示和文案。开启后选择其他商品不改变该替换位置。
6. 客户端试用切换开启后选择其他商品时，开关和已形成的商品列表保持不变，当前购买按钮使用新选中 SKU 的文案；关闭开关时保持当前选中位置，并恢复此前替换位置的基础 SKU 展示和文案，不得残留上一 SKU 文案。
7. 在真实交易条件允许使用运营文案时，订阅按钮优先级为：当前实际 SKU 文案 → 组级订阅按钮兜底文案 → 客户端固定默认 `SUBSCRIBE`，Page／Modal 一致。空值只触发下一级，不因文字为空阻止保存、启用或购买；第 7.6.7 节的资格安全展示优先。
8. 独立试用 SKU 保持自身 Product ID，不使用关系替换字段；有资格时使用自身营销字段，无资格或资格未知时按第 7.6.7 节使用中性展示。
9. 不恢复 SKU `是否展示`字段；配置中保留的所有页面展示 SKU 均参与展示。
10. 每组配置只设置一个默认选中的页面展示 SKU。默认选中只配置在页面展示 SKU 上，默认状态属于该商品位置的基础 SKU；不新增`默认试用 SKU`配置字段，关联试用目标不单独参与默认项计算。

#### 7.5.3 增加、移除与排序

1. `+ 增加 SKU`在末尾追加一张空白卡片，不改变其他输入。
2. 新卡片商品类型默认选择`订阅`，直接加载项目指定订阅组内商品，不显示订阅组字段。
3. 指定订阅组内商品和一次性购买商品各自显示读取中、读取失败可重试及成功但为空状态；局部加载不阻塞营销文案编辑。
4. 每张卡片提供上移、下移、移除。
5. 第一项上移禁用，最后一项下移禁用。
6. 排序移动整个 SKU 对象，包括字段、默认状态和试用关系。
7. 序号按当前顺序实时更新。
8. 允许移除到 0 张，但保存时必须提示至少保留一张。
9. 移除页面展示 SKU 只影响当前配置，不删除或修改 Apple 商品，也不影响已有购买权益。

#### 7.5.4 已取消“是否展示”

- 页面展示 SKU 卡片没有`是否展示`字段。
- 配置中保留的所有页面展示 SKU 都参与客户端展示。
- 不希望展示时必须从本组移除。
- 客户端不得继续读取旧版本中的隐藏状态影响展示结果。

#### 7.5.5 价格展示

##### 实际周期价格与真实扣费信息

- 所有价格模式都以 StoreKit 返回的完整本地化正常周期价格、币种和实际计费周期作为主要价格；一次性商品明确一次性扣款。
- 不得让用户只看到年费／月费的周均折算值。当前可领取免费试用时，同时突出试用期限及结束后的完整续订金额和周期。
- `{price}`表示当前购买目标的正常计费周期本地化价格，不代表试用 0 元或周均价。
- 运营价格说明可为空，但第 6.7 节的真实交易信息始终展示；商品价格、周期等必要事实不足时，该商品暂不可购买，不补 0 或固定美元示例价。

##### 折算周均参考价

选择“实际周期价格 + 折算周均参考价”时，保留上述主价格，再增加较次要的周均参考值；不改变实际扣费周期或金额。后台不维护金额、币种或计算结果。

设 P 为当前实际购买目标的正常周期价格：

| 商品周期 | 周均价公式 |
| --- | --- |
| 周订阅 | P |
| 月订阅 | P × 12 ÷ 52 |
| 季度订阅 | P × 4 ÷ 52 |
| 年订阅 | P ÷ 52 |
| 一次性 | 不支持周均参考价 |

1. 从 Apple 原始数值精确计算，不反算格式化字符串；中间不舍入，最终四舍五入两位，使用对应本地化符号和分隔格式。
2. Page 和 Modal 使用同一公式；试用状态的 P 为试用结束后的正常周期价格，不把免费期 0 元代入。
3. {price} 仍保留 Apple 正常周期本地化格式，不以周均值替换。
4. 不在表中的真实周期仅显示完整周期价格，禁用周均选项；不得猜测换算公式。
5. 模式仅影响辅助周均值是否出现，不影响主价格、固定交易摘要、按钮文案、真实 Product ID 或收入金额。

#### 7.5.6 购买按钮正上方说明

该区域区分固定真实交易摘要和可选营销说明，不新增后台计费事实输入字段。基础和关联试用状态各自保留原有说明方式／自定义文本；不得把空营销文本解释为隐藏计费信息。

##### 自定义文本

- 可为空，最多 500 字符；为空时只省略营销说明，固定交易摘要仍展示。
- 仅支持 {price}，表示当前实际购买目标的正常周期本地化价格；不代表试用 0 或周均价，其他占位符拒绝。
- 不得填写与真实交易不一致的金额、周期或无条件免费承诺；独立试用无资格／资格未知时不展示自定义营销文案。
- 旧纯文本保持自定义方式；切换方式不清空保存值，切回恢复。

##### 自动商品说明与固定真实交易摘要

按当前实际 Product ID 的真实商品信息和用户资格生成，不解析 ID 命名，不使用原型金额。自动说明与固定摘要内容相同时合并展示一次。

| 已确认状态 | 摘要内容 |
| --- | --- |
| 当前符合有效免费试用资格 | 实际试用期限 free, then 本地化正常价格／真实周期 |
| 普通订阅或明确无资格 | 本地化正常价格／真实周期，并明确按该周期计费；不承诺免费 |
| 独立试用资格未知 | Standard price: 本地化正常价格／真实周期；Any available offer is confirmed in the App Store. 不承诺本次立即扣款或一定免费 |
| 一次性非消耗型 | 本地化一次性价格，明确 one-time purchase |

1. 试用期限使用真实单位；1 day、N days 按真实数据展示，自然月保留 month，不猜测 30 天。
2. 试用结束后的价格和周期必须完整；不把周均参考值放入计费摘要替代真实金额。
3. 选择卡片、开关或资格状态改变后，按最终 Product ID 和真实资格同步更新，不残留上个商品的价格、文案或按钮。
4. 独立试用适用第 7.6.7 节；资格未知不能当成有资格，也不能自动改成另一个 Product ID。
5. 如果缺少金额、币种、真实周期或当前试用必要信息，当前交易状态不可提交；不能只隐藏残缺说明后继续购买。独立商品正常周期信息完整但资格未知时，允许使用上述标准价格说明继续购买。
6. 营销说明可空与交易信息完整是两个判断；后台保存不要求人工补计费值，客户端购买前必须满足真实信息完整性。
7. 按钮内文案保持纯文本及三级回退；独立试用无资格／资格未知的安全按钮固定 SUBSCRIBE，优先于运营 CTA。

| 规则 | 要求 |
| --- | --- |
| 数量 | 每个普通付费源 SKU 最多一个试用目标；同组页面配置允许多组关系；开启切换功能时至少一组有效关系 |
| 关系源 | 必须是 Apple 商品信息中不带免费试用的自动续期订阅商品 |
| Product ID | 普通付费源与试用目标 Product ID 必须不同 |
| 周期 | 两个商品周期必须一致 |
| 所属订阅组 | 普通付费源与试用目标都必须来自项目指定订阅组 |
| 订阅等级 | 两个商品的 Apple 订阅等级必须一致 |
| 试用信息 | 目标商品的 Apple 商品信息必须包含免费试用 |
| 一次性 | 一次性商品不提供试用关系 |
| 同组独立卡片 | 当前关系目标不得同时作为本组页面展示 SKU；同一试用商品可在其他配置中独立展示 |
| 同组关系目标 | 一个试用 SKU 只能被本组一个关系源使用；不跨配置限制 |
| 客户端卡片 | 关系源和目标共用关系源所在的一张商品卡片；目标不额外生成页面展示卡片 |
| 排序 | 试用 SKU 复用所属关系源卡片的位置和顺序 |
| 价格模式 | 试用 SKU 复用所属关系源卡片的价格展示方式 |
| 默认项 | 关联试用 SKU 没有独立默认选中字段，不新增`默认试用 SKU`配置；只复用关系源卡片的位置 |
| 展示状态 | 试用 SKU 没有独立`是否展示`字段 |

下拉框只展示：

1. Apple 商品读取结果中包含免费试用的商品。
2. 来自项目指定订阅组，并与当前普通付费源 SKU 周期一致、订阅等级一致的商品。
3. 未被本组页面展示 SKU 作为独立卡片使用的商品。
4. 未被本组其他普通付费源关联的商品；当前源已经选择的目标始终保留在自身下拉框中正常回显。

关联试用 SKU 直接从同一个项目指定订阅组中选择，不提供独立商品类型或订阅组控件。其 Product ID 下拉占整行，展开后直接滚动选择；选项和选中后与页面展示 SKU 使用相同的`Product ID · 苹果后台参考名称`格式，参考名称缺失时只显示 Product ID，免费试用辅助标识可保留。

每个符合条件的普通付费订阅卡片都可以独立建立一组关系，不要求所有订阅卡片都有关系。一次性商品和独立试用 SKU 卡片不提供关联试用目标操作。

各关系中的试用目标在本配置内继续占用 Product ID，即使后台关闭试用切换功能也参与去重。如需将某个目标改为本组独立展示卡片，必须先在对应源卡片使用`解除试用关联`释放目标；未被本组关系占用的试用商品可直接添加为页面展示 SKU。

#### 7.6.4 关闭后台试用切换功能

当`启用试用切换开关 = 关闭`：

- 保留已经填写的关系和试用文案。
- 新增和编辑表单隐藏`关联试用 SKU`下拉框以及全部试用替换文案字段，不允许在关闭状态下建立或编辑关系。
- 如存在保留关系，关系源卡片只显示`已保留但未启用`摘要和`解除试用关联`操作，不把隐藏字段伪装成可编辑状态。
- 客户端不展示试用开关，不使用试用关系和试用文案。
- 关系源卡片只展示并购买自身普通付费 SKU；保留的试用目标不额外生成商品卡片，也不参与购买。
- 未建立关系或替换文案不完整时，不阻止页面展示 SKU 配置保存。
- 已保留关系仍必须满足普通付费源、试用目标、周期和同组去重规则，不能静默保存错误关系。
- 页面展示 SKU 校验仍然执行。
- 独立试用卡片继续保留，展示与购买按第 7.6.7 节自身资格规则执行。
- 关闭切换功能不得解释为禁用所有试用商品。

#### 7.6.5 开启后台试用切换功能

当`启用试用切换开关 = 开启`：

- 新增和编辑表单显示关系选择和试用替换文案配置入口。
- 试用开关文案必填。
- 至少有一组完整有效关系；不要求所有普通付费订阅 SKU 都建立关系。
- 每个源 SKU 最多一个目标，同组目标不得重复；所有已选择目标的关系都必须满足 Product ID、周期、Apple 试用信息和同组占用限制。
- 每组已建立关系的试用商品展示名称必填；关联试用 SKU 订阅按钮文案可为空。
- 每组已建立关系的试用文案都必须符合长度和变量限制。

#### 7.6.6 关系变更与移除

1. 修改关系源页面展示 SKU 的商品类型或 Product ID 后，如果原试用关系不再满足源商品属性、项目指定订阅组、同周期、同等级或引用条件，立即清空试用 Product ID。
2. 提示重新选择匹配的试用 SKU。
3. 已填写试用文案继续保留。
4. 试用切换功能开启时，修复关系前不得保存。
5. 移除带试用关系的普通付费源 SKU 时，同时移除该卡片自己的关系，不影响其他卡片关系。
6. 移除后仍有至少一组有效关系时，后台试用切换功能保持开启；无需关闭配置级开关。
7. 移除或解除最后一组关系时，提示将同时关闭本组试用切换功能；用户确认后移除关系并关闭开关，试用开关文案可保留。
8. 用户取消最后一组关系的移除确认时，卡片、关系、开关和文案全部保留。
9. 后台关闭试用切换且存在保留关系时，每个关系源卡片分别提供`解除试用关联`操作；解除其中一组不影响其他保留关系。
10. 解除操作只清空该源卡片的试用目标 Product ID，保留已经填写的替换文案；目标商品立即释放，可被本组其他源选择或作为独立页面展示 SKU 选择。
11. 解除操作只修改当前编辑状态；保存成功后持久化，取消或放弃编辑后恢复最近一次成功保存的关系。

#### 7.6.7 独立试用 SKU

带有效介绍性免费优惠的订阅商品可以作为独立页面卡片，无需普通商品配对或开启关联切换。添加、移除、排序、默认项仍按页面 SKU 规则，购买始终使用该卡片自身 Product ID。

| 当前用户／商品状态 | 卡片与按钮 | 购买条件 |
| --- | --- | --- |
| 真实优惠可用且用户有资格 | 使用该 SKU 自身营销字段和 CTA 三级回退，同时展示真实试用期限及续订条件 | 提交前再确认实际商品和资格；信息完整才提交 |
| 明确无资格或该地区／时间无有效优惠 | 保留位置、默认选择和 Product ID；标题使用客户端中性 Premium，隐藏后台副文案、角标、价格营销说明和自定义说明，按钮固定 SUBSCRIBE；正常周期价格和摘要保留 | 允许按真实普通订阅条件购买，不切换到其他 SKU |
| 资格未知 | 与上行一样使用中性展示，摘要标明 Standard price，并提示可用优惠由 App Store 确认；不显示任何确定免费承诺 | 基础金额、币种和周期完整时可继续；不把未知记录为无资格 |

1. 安全展示由商品优惠／资格状态确定，不用模型或标题字符串识别“是否承诺免费”。本期不新增一套运营可配的无资格文案字段。
2. 只有确认有资格时才采用独立试用商品的营销名称、CTA 及其他自由文案。无资格／未知时不读取组级 CTA，避免组级免费承诺继续生效。
3. 后台保存的原文不被清空，安全展示仅作用于当前页面；用户后续重新进入并确认有资格时，可使用该 SKU 配置。
4. 若先显示免费试用，提交前确认资格或优惠已失效，阻止本次提交并提示条件变化；更新中性展示后，必须由用户再次明确点击购买，不能在同一次点击中静默转为收费。
5. 资格变化不隐藏整张卡片、不重排、不更换 ID，也不因为资格未知就把成功加载的商品当成加载失败。
6. 基础价格／币种／周期缺失按商品不可购买处理；实际购买始终由 Apple 返回的真实交易条件和验证结果决定。

#### 7.6.8 Apple 试用信息边界

- 后台目录或运营配置不创建 Apple 优惠，不证明用户资格。免费试用限定真实有效的介绍性免费优惠；目录按地区、起止时间和优惠类型提供事实。
- 客户端区分有资格、无资格、未知，并确认实际优惠期限、正常价格和周期；不能仅使用后台 hasFreeTrial 判断当前用户。
- 资格同时约束关联试用切换和独立 SKU 的免费承诺。独立 SKU 保留商品本身，按第 7.6.7 节切换安全展示。
- 关联切换只有至少一组普通商品／目标商品成功加载、关系有效、优惠真实可用且用户符合资格时才提供。
- 后台关闭、无有效关系或全部目标资格未知／不可用时隐藏关联开关；不阻塞其他具备完整计费信息的商品。
- 提交前优惠失效不能静默改为另一商品或在同一次点击中转成普通收费购买。

#### 7.7.2 试用不可用与购买失败分支

##### A. 进入页面时试用切换不可用

客户端显示试用切换开关前，必须同时确认：

1. 当前页面配置启用试用切换功能。
2. 至少一组后台关系完整且有效。
3. 至少一组关系的普通与试用商品均成功从 StoreKit 返回。
4. 至少一组关系目标的 Apple 试用能力真实可用。
5. 当前用户至少符合一组关系目标的试用资格。

任一条件不满足，或资格尚未确认时：

- 隐藏试用切换开关。
- 继续展示和允许选择全部有效页面展示 SKU，包括独立试用 SKU。
- 不阻塞已经可用的页面展示商品购买。
- 不显示虚假试用时长、价格或资格。

某一组关系不可用时，仅将该关系排除出客户端试用切换候选；只要仍有其他有效且可用关系，客户端试用开关可以继续提供。对应源卡片仍按普通付费 SKU 正常展示和购买。

用户点击打开试用开关时，客户端按同一套既有规则重新确认当前关系及候选关系是否可用。当前选中位置没有可用关系时，按后台展示顺序查找第一个可用关联位置；独立试用 SKU 不参与该候选顺序。全部关联均不可用时，开关保持关闭、当前选中位置不变，并沿用既有试用不可用提示，不新增错误类型或校验体系。

上述条件判断关联切换是否可提供；独立试用 SKU 同时按第 7.6.7 节确认展示口径。无资格或未知时保留卡片和 Product ID，使用中性名称、固定 SUBSCRIBE 与真实标准价格说明，隐藏免费营销承诺；不把资格未知视为商品加载失败。

##### B. 普通购买取消或一般网络/服务失败

- 保留当前商品选择和当前试用状态。
- 沿用既有购买反馈。
- 不擅自切换购买目标。
- 本分支不包含提交前已经确认试用商品或资格失效的情况。

##### C. 已通过切换关系选择试用，但提交前确认商品或资格失效

- 阻止本次购买并明确提示试用不可用。
- 不再允许继续提交该无效试用购买。
- 引导用户主动关闭试用切换或重新选择其他页面展示 SKU。
- 用户完成明确选择后，才允许提交普通付费购买。
- 不静默替换为普通付费 SKU，不自动按直接付费继续提交。
- 本分支不适用“一般购买失败后保留试用并允许继续提交”的处理。

### 7.8 保存校验

#### 7.8.1 配置级

- 配置名称必填且不超过 100 字符。
- 页面类型必选。
- 已生效配置的页面类型必须保持只读；未生效配置允许修改类型。
- 组级订阅按钮兜底文案可为空；填写时不超过 100 字符。为空时不阻止保存，当前实际 SKU 文案也为空时使用客户端固定默认 `SUBSCRIBE`。
- 关闭延迟必须为非负整数，不设置业务时长上限。
- 页面展示 SKU 列表至少保留一个商品。
- 整组页面展示 SKU 必须且只能一个默认选中项。

#### 7.8.2 页面展示 SKU

- 商品类型必选，值只能为`订阅`或`一次性购买`；新增 SKU 默认选择`订阅`。
- Product ID 必选，且必须与所选商品类型匹配；订阅商品必须来自项目指定订阅组，一次性购买商品必须来自本次可配置的一次性购买范围。
- 新增或更换 Product ID 必须来自当前范围成功读取的 Apple 商品；不带试用订阅、带试用订阅和 Lifetime 商品均可成为页面展示 SKU。
- Apple 商品读取失败时，已有配置中保存的 Product ID 不得仅因本次读取失败被清空或判定为已删除；恢复读取后再按最新商品信息校验新选择和试用关系。
- 同组 Product ID 不重复。
- 当前配置中作为试用切换关系目标的 Product ID 不得同时作为页面展示 SKU；关闭切换功能但保留关系时仍执行该去重。
- 商品展示名称必填且不超过 100 字符。
- 名称下方副文案不超过 300 字符。
- 右上角角标文案不超过 100 字符。
- 价格下方说明文案不超过 200 字符。
- 页面展示 SKU 订阅按钮文案可为空；填写时不超过 100 字符。普通订阅、独立试用 SKU 和一次性购买使用同一校验规则。
- 自定义文本方式下，购买按钮正上方说明文案不超过 500 字符；允许为空。
- 购买按钮正上方说明方式必须为`自定义文本`或`自动商品说明`；自定义文本允许为空，自动方式不要求后台文案。
- 价格展示方式适用于商品类型。
- 副文案、角标、价格下方说明及自定义按钮上方说明只允许`{price}`变量；三处按钮文案只允许纯文本，拒绝任何花括号。

#### 7.8.3 试用切换关系与替换字段

- 每个源 SKU 最多一个目标，同组允许多组关系；关系存在时，无论切换开关是否开启都校验源/目标角色、Product ID、项目指定订阅组、周期、订阅等级和同组去重。
- 关系源必须为 Apple 商品信息中不带免费试用的自动续期订阅商品；Lifetime 和独立试用 SKU 不可作为关系源。
- 两个 Product ID 不同，且必须属于同一 Apple 订阅组、周期一致、订阅等级一致。
- 试用目标的 Apple 商品信息必须包含免费试用，且不是 Lifetime 商品。
- 试用目标不在页面展示 SKU 列表中重复出现。
- 同一试用目标不得被本组多个源 SKU 重复引用；当前源已选目标必须可以正常回显。
- 启用试用切换时，试用开关文案必填且不超过 100 字符，并且必须至少存在一组有效关系；未关联的普通订阅 SKU 不阻止保存。
- 启用试用切换时，每组已选关系的试用展示名称必填且不超过 100 字符；关联试用 SKU 订阅按钮文案可为空，填写时不超过 100 字符。
- 启用试用切换时，试用名称下方副文案不超过 300 字符、右上角角标文案不超过 100 字符、价格下方说明文案不超过 200 字符；按钮上方说明方式必须为允许枚举，自定义文本方式下文案不超过 500 字符且允许为空。
- 启用试用切换时，关联试用按钮只允许纯文本、拒绝任何花括号；副文案、角标、价格说明、自定义说明只允许`{price}`变量。自动交易摘要不是后台模板，不保存`days`、`price`、`period`变量值。
- 关闭试用切换时，不要求建立关系，也不校验隐藏替换文案的完整性；已保留关系仍执行结构和同组去重校验，并可通过解除操作释放目标。

校验失败时保留输入，字段附近提示具体原因，并提供汇总错误。不得只显示通用`保存失败`。

### 7.9 正常流程

#### 7.9.1 完整配置流程

```text
进入订阅页配置
→ 新增或编辑一组配置
→ 添加 SKU
→ 选择商品类型
├─ 订阅：直接从项目指定订阅组内选择具体 Product ID
└─ 一次性购买：从一次性购买商品中选择具体 Product ID
→ 填写页面展示文案、设置排序和默认选中
→ 按需配置试用开关及关联试用 SKU
→ 保存
→ 按既有规则启用
```

页面展示 SKU 和独立试用 SKU 使用同一商品类型与 Product ID 选择流程；关联试用 SKU 直接从同一个项目指定订阅组中选择，不重复选择商品类型或订阅组。所有路径最终都必须选择具体 Product ID；页面营销文案始终由产品配置。

#### 7.9.2 客户端读取

```text
进入 Subscription Page / Paywall Modal
→ 读取对应页面类型的生效配置
├─ 有效 → 冻结为当前页面配置快照
│  → 请求配置引用的 StoreKit Products
│  → 按后台顺序过滤不可用商品
│  → 试用开关默认关闭
│  → 唯一默认页面展示 SKU 可用时选中其基础商品；不可用时沿用既有规则选择第一个可用页面展示 SKU
│  → 切换关系与资格条件满足时提供试用切换开关
└─ 无效/关闭/失败 → 使用对应客户端兜底配置
```

#### 7.9.3 购买

```text
读取当前选中页面展示卡片
→ 判断它是否为试用开关开启时记录的关联替换位置
├─ 是 → 该位置关系目标试用 SKU Product ID
└─ 否 → 当前卡片自身 Product ID（包括独立试用 SKU）
→ 按最终购买目标同步价格、商品文案、按钮上方说明和订阅按钮文案
→ 再次确认目标 Product 可用且界面信息一致
→ 调用既有 Apple Purchase
→ 按现有 Success / Pending / Cancelled / Failed 规则处理
→ 仅在实际交易确认成功后，按第 7.12.2 节上报收入事件
```

### 7.10 异常、返回与状态保留

| Product ID 缺失或与商品类型、项目指定订阅组范围不匹配 | 阻止配置保存并定位当前 SKU | 保留商品类型与所有营销文案 |

| 试用切换关系结构无效 | 无论切换是否开启都阻止保存，提示修复源/目标、指定订阅组范围、周期、等级或同组重复 | 保留试用替换文案 |
| 同组多个源重复选择同一试用目标 | 阻止保存，并在重复关系附近提示目标已被占用 | 保留所有关系和文案，允许逐项解除或更换 |
| 切换关闭且未配置关系或替换文案不完整 | 允许保存页面展示 SKU 配置 | 保留已填写关系和文案；独立试用按自身资格展示 |
| 切换关闭且存在保留关系 | 隐藏关系编辑和替换文案，只显示未启用摘要与解除操作 | 客户端忽略关系；解除后目标可作为独立卡片选择 |
| 配置新增/保存明确失败且确认未写入 | 结束 Loading，提示失败，恢复适用操作 | 保留输入或原配置；编辑保存时服务端旧版本继续有效 |
| 生效切换明确失败且确认未写入 | 回到最后确认状态，恢复适用操作 | 旧生效配置继续有效；不出现两组同时生效 |
| 任一后台写入达到 15 秒仍未确认 | 进入状态核对，不直接认定失败，不开放重复提交 | 保留输入和原请求标识；相关写入操作继续禁用 |
| 状态核对在最多 15 秒内确认成功 | 按实际写入结果更新列表、详情或生效状态 | 已成功操作不得重复执行 |
| 状态核对确认原请求未写入 | 按明确失败处理并恢复适用操作 | 保留输入或原记录 |
| 状态核对失败或再次超时 | 结束等待，允许离开，提示`暂时无法确认操作结果，请稍后重试` | 保留输入；再次提交前先核对原请求状态 |
| 原请求迟到响应 | 仅在请求上下文仍有效且未有更新结果时处理 | 不得覆盖更新后的页面或已经确认的操作结果 |
| 取消/关闭编辑 | 有修改时显示放弃确认 | 取消放弃则继续保留输入 |
| 配置关闭/无生效配置 | 客户端使用对应页面类型兜底 | 当前已打开页面不热切换 |
| 配置整体无效/获取失败 | 客户端使用对应兜底配置 | 不制造可购买假数据 |
| 进入页面时试用切换不可用或资格未确认 | 隐藏关联开关，保留有完整计费信息的卡片 | 独立试用按有资格／无资格／未知展示，不承诺未经确认的免费优惠 |
| 独立试用 SKU 的用户资格不符合或无法确认 | 保留卡片位置和 Product ID；使用中性 Premium、SUBSCRIBE 与真实标准价格说明，隐藏试用营销字段 | 不清空后台文案；不把未知当作无资格或加载失败；已显示免费后资格失效不得同次点击转收费 |
| 独立试用 SKU 商品加载或价格失败 | 按既有商品失败规则处理 | 不将资格问题误判为加载失败；不显示虚假价格 |
| 普通购买取消或一般网络/服务失败 | 沿用既有反馈，不切换购买目标 | 保留当前商品选择和试用状态 |
| 提交前确认试用商品或资格失效 | 阻止购买并提示试用不可用；等待用户明确关闭试用切换或选择其他页面展示 SKU | 不再允许提交无效试用；不静默转为普通付费 |
| 点击购买按钮、切换 SKU 或打开 Apple 支付 | 不上报订阅成功或成功收入事件 | 等待实际交易结果 |
| 免费试用开始且本次实际支付为 0 | 成功事件中的本次交易金额为 0；不得使用试用结束后的正常订阅价格 | 后续转付费与续订按实际扣款另行处理 |
| 购买取消、失败、待确认或交易未验证 | 不作为成功收入上报 | 保留既有购买状态和反馈 |
| 收到重复购买回调、监听更新或上报重试 | 按同一交易幂等处理，不重复上报 | 不重复累计收入或购买次数 |
| Restore 恢复既有购买 | 不产生新的成功收入事件 | 只恢复权益，不重复计入历史交易收入 |
| Apple Product 缺失 | 该商品不可选/不可买；按既有商品失败规则 | 不填 0，不使用示例价格 |
| Apple 价格读取失败 | 不显示伪造价格，不允许展示与购买目标不一致 | 按第 6.6 节本期 15 秒总预算处理 |
| 全部兜底商品也失败 | 展示既有 Product Loading Failed / Timeout 状态 | 保持 Page/Modal 可按既有规则关闭 |
| 商品加载最终失败或没有可购买商品 | 按既有失败退出规则提供关闭入口 | 不继续受关闭按钮长延迟阻塞；不重新开始延迟计时 |
| Purchase Pending | 沿用现有 Pending 规则，禁止重复提交 | 保持当前 Page/Modal 与选择 |
| Restore | 保留现有入口、互斥、结果及分阶段超时，当前部分阶段为 25 秒；不套用商品页 15 秒总预算 | 本期不修改 Restore，不宣称已经实现端到端 15 秒／25 秒保证 |

### 7.11 客户端兜底

订阅页与订阅大弹窗分别判断是否进入客户端兜底，互不影响。本期不新增后台兜底配置模块。

触发条件：

- 后台对应页面类型没有生效配置。
- 网络不佳导致后台配置获取失败或超时。
- 配置为空、结构缺失、版本不兼容、整体校验失败、无法使用，或其他未取得可用后台配置的情况。

#### 7.11.1 对应页面最新确认 UI 稿

前端使用对应页面最新确认的 UI 稿确定兜底 SKU 和展示配置。不再以特定 App 版本为依据，也不限定固定三个 SKU。

| 页面类型 | 兜底依据 | UI 稿决定的内容 |
| --- | --- | --- |
| 订阅页 | 订阅页最新确认 UI 稿 | 商品组合、展示顺序、默认选中和展示文案 |
| 订阅大弹窗 | 订阅大弹窗最新确认 UI 稿 | 商品组合、展示顺序、默认选中和展示文案 |

规则：

1. 订阅页、订阅大弹窗分别以各自最新确认的 UI 稿为准，互不复用或推导另一页面的兜底组合。
2. UI 稿中的示例金额不作为固定售价；实际价格、币种和可购买状态仍读取对应 Apple 商品信息。
3. UI 稿未注明的真实 Product ID 由产品与研发核对，不根据商品名称、周期文案、展示顺序或其他字符串猜测。
4. UI 稿中只出现方案名称但未明确 Product ID 时，不得使用原型示例 ID 或按方案名称自行补齐。
5. UI 稿更新并被确认为最新版本后，后续客户端兜底以该稿为准；本 PRD 不固定 SKU 数量、档位名称、展示顺序或默认项。

#### 7.11.2 兜底读取规则

1. 前端使用对应页面 UI 稿确认的 Product ID 与展示配置；UI 稿未注明 Product ID 时，必须先完成产品与研发核对。
2. 实际价格、币种、可购买状态和试用信息仍从 Apple 获取；不得使用 UI 稿示例金额、原型示例价格或固定可购买状态冒充真实数据。
3. 订阅页和订阅大弹窗分别判断；一个页面类型进入兜底不改变另一类型已取得的有效后台配置。
4. 当前页面实例一旦使用兜底配置，迟到的后台配置结果不得突然替换 SKU、默认项、说明文案或购买目标。
5. 后台配置读取、校验和兜底商品加载共用已确认的整体等待预算；进入兜底流程不重新获得完整等待时间。
6. 部分兜底 Product 加载失败时，只保留实际成功返回且可购买的商品，并按原顺序展示；默认项不可用时选择第一个可用商品。
7. 兜底商品全部加载失败或价格无法取得时，沿用既有商品加载失败与重试状态；不得显示 0、固定美元价或可购买假数据。
8. 仅试用切换功能失败时，不进入整体兜底；隐藏切换开关并继续所有有效页面展示 SKU，独立试用商品不受影响。

### 7.12 与现有购买及收入事件系统的关系

#### 7.12.1 既有购买系统

以下行为继续引用 [TCG_Card_App_v1.1_PRD.md](../../v1.1.0/00-product/TCG_Card_App_v1.1_PRD.md)；商品页总预算按本版明确变更，Restore 时序以第 6.6 节保持当前实现：

- StoreKit 商品加载与最多 3 次自动重试。
- 本期商品页采用第 6.6 节的 15 秒总 Deadline，明确替代当前商品加载默认 25 秒；不是对当前源码行为的描述。
- 只有成功返回的 Product 可选择和购买。
- Purchase Success / Pending / Cancelled / Failed / Unverified。
- Restore Success / Not Found / Failed / Timeout。
- Purchase 与 Restore 不并发。
- Subscription Page 的 Subscription Success 与来源返回。
- Paywall Modal 的 `blocked_action` 恢复。
- Terms、Privacy 和原容器关闭规则。

后台配置不得覆盖或弱化这些规则。

#### 7.12.2 本次订阅收入事件上报

本节定义产品口径，不新增后台埋点配置字段。SDK 调用方式、字段映射和去重实现由研发确定，不作为产品指定技术方案。

##### Singular 收入型事件

| 实际成交商品 | Singular 事件名称 | 匹配依据 |
| --- | --- | --- |
| 周试用 SKU | `card_weekly_trial` | Apple 确认成功交易中的实际成交 Product ID |
| 月订阅 SKU | `card_monthly` | Apple 确认成功交易中的实际成交 Product ID |

规则：

1. 事件名称必须严格使用上表值，不得改写大小写、下划线或单复数。
2. 根据实际成交的 Product ID 匹配事件，不根据页面展示名称、营销文案、页面位置或试用开关状态判断。
3. 周试用 SKU、月订阅 SKU 的真实 Product ID 与事件对应关系由研发结合正式 Apple 商品核对；本 PRD 不使用原型示例 Product ID 或命名字符串猜测填写。
4. 其他 SKU 继续沿用已有 Singular 事件规则，本节不为其新增或改名。

##### Firebase 订阅成功事件

1. 继续使用项目现有订阅成功事件名称，不额外创造新的 Firebase 事件名称。
2. 订阅成功事件同时上报本次订阅价值和对应币种。
3. 价值和币种来自确认成功的实际交易；不得从后台展示配置或格式化展示文案反推。

##### 金额、触发与去重口径

1. 只有 Apple 交易确认成功后，才可上报成功收入。点击订阅按钮、切换 SKU、打开 Apple 支付页或仅收到购买发起结果均不是成功收入触发点。
2. 金额使用本次交易实际支付金额及对应币种，不使用周均折算价、后台示例价、页面展示价或预计未来续订金额。
3. 免费试用开始时，本次实际支付金额为 0；不得把试用结束后的正常订阅价格作为本次收入。事件如需携带价值，必须按本次交易上报 0 和对应币种。
4. 试用转付费及后续续订沿用已有收入上报规则，分别以对应实际扣款交易的金额和币种为准。
5. 取消、失败、待确认（Pending）或未验证交易不作为成功收入上报。
6. Restore 只恢复既有购买与权益，不重复计入收入；同一笔交易不得因购买回调、交易监听、重试、迟到响应或重复回调重复上报。
7. 研发必须核对现有自动采集、客户端和服务端收入上报链路，确保同一目标统计平台内同一笔交易只计收一次。
8. 收入事件上报失败不得把已确认成功的 Apple 购买改写为购买失败；失败处理沿用现有收入上报规则。

- 页面展示文案
- 页面展示 SKU 订阅按钮文案
- 购买按钮正上方说明方式
- 保留的自定义购买按钮正上方说明文案
- 可选 TrialOverride

商品类型用于确定后台商品读取范围，不代替`PageDisplaySkuConfig`中的具体 Product ID。项目指定订阅组属于接入上下文，不是页面配置字段。编辑已有记录时可按 Product ID 对应的 Apple 商品信息恢复商品类型；本文不据此规定接口字段或数据库结构。

一个配置可以有多个带`TrialOverride`的`PageDisplaySkuConfig`。每个页面展示 SKU 最多一个`TrialOverride`，且同一配置内各`TrialOverride`的试用 Product ID 必须唯一。

#### TrialOverride

- 普通付费源 Product ID（由所属页面展示 SKU 提供）
- 试用 Product ID
- 试用展示文案
- 关联试用 SKU 订阅按钮文案
- 试用购买按钮正上方说明方式
- 保留的试用自定义购买按钮正上方说明文案

`TrialOverride`仅在配置级试用切换功能开启且客户端试用切换打开时参与展示与购买。关闭后台切换时可保留数据，但客户端必须忽略；试用目标不生成额外页面展示卡片。

客户端先按实际 Product ID 和资格确定是否采用中性安全展示；允许使用营销字段时，使用 PageDisplaySkuConfig 或 TrialOverride 的 CTA，空值回退组级，再回退 Page／Modal 共用 SUBSCRIBE。三处 CTA 仅纯文本，按钮上方说明不参与其优先级。

服务端必须保证：

- 同组页面展示 Product ID 不重复，试用目标占用关系不冲突。
- 引用完整。
- 同页面类型最多一个生效配置。
- 生效替换原子性。
- 新增/保存幂等性。
- 客户端能够识别配置结构版本。

87. 后台或兜底 Apple 商品、价格获取失败时不填 0、不显示示例价、不允许错配购买；全部失败时展示既有失败状态并提供关闭入口。

92. iOS 消费 Apple 配置；Android 保持原行为且不受 Apple 目录失败影响。
93. 当前既有商品／旧客户端行为保持；新增商品跨版本支持未完成核验时不得以新字段兼容代替权益恢复验收。

## 11. 最小实施方案（设计草案，尚未实现）

### 11.1 范围与依赖

在现有 React Admin、Hono API、PostgreSQL 和 Flutter 订阅链路上增量实现。商品目录读取与系统准入先于启用；配置服务先于 Admin／Flutter 联调；真实商品和兜底映射先于相关发布验收。

复用现有管理员角色和一般配置权限：super_admin、operator 可读取、编辑与启用本模块，所有管理接口经过服务端 requireAdmin；不新增角色或权限平台。若业务需要将启用权限进一步收紧，应作为明确权限调整，不只隐藏按钮。

不改变现有购买证据、session grant、账号隔离、通知或收入真值来源，不创建 D1 路径，不增加配置删除、复制、版本中心、A/B 或实时推送功能。

### 11.2 建议接口与合同

以下路径是待编码的设计，不代表服务已提供；统一使用现有成功／错误包络。

| 接口草案 | 用途与关键合同 |
| --- | --- |
| GET /api/v1/admin/subscription-products | 管理端只读目录；按订阅／指定非消耗型范围读取，处理完整分页。App／组由服务端环境确定，不接受任意客户端 App ID；返回系统准入状态和明确原因 |
| GET /api/v1/admin/subscription-configs | 列表；启用状态来自真实生效指针，失败不返回假空列表 |
| GET /api/v1/admin/subscription-configs/:id | 编辑内容、revision 和生效状态；不得把读取失败变为空表单 |
| POST /api/v1/admin/subscription-configs | 新增后不生效；请求带幂等标识 |
| PUT /api/v1/admin/subscription-configs/:id | 保存完整编辑副本，带 expected_revision；保存不改变生效归属，已生效类型不可改 |
| PUT /api/v1/admin/subscription-configs/active/:page_type | 设置目标 config_id 或关闭；携带预期 active_revision 及目标内容 revision，防止确认 A→B 却覆盖刚被他人启用的 C |
| GET /api/v1/admin/subscription-config-mutations/:request_id | 核对同一写入的结果；未找到记录表示未知，不直接判定失败 |
| GET /api/v1/subscription-display-config?type=page 或 modal | 只返回当前 App 作用域下生效配置的必要展示字段；无配置以成功且 data=null 表达，故障仍为失败；Cache-Control: no-store |

每套配置带 schema_version 与内容 revision；本模块初始 schema_version=1，不把 PRD 1.14 当接口版本。基础和关联 CTA 均可省略或空串，纯空白按空；保留原字段，未知结构版本触发本地兜底。现有 /app-config、购买、Restore 接口不被替换，也不要求旧客户端新增参数。

管理接口按环境固定作用域；公开展示响应不包含凭据、操作人、内部校验详情或写入状态。Apple 私钥留在服务端配置，不进入浏览器或 Flutter。

### 11.3 最小数据结构和事务

建议三类持久化对象，表名待编码时按仓库风格确定：

| 对象 | 必要字段／约束 | 作用 |
| --- | --- | --- |
| 展示配置 | id、scope、page_type、name、schema_version、body、revision、updated_by／at | body 保存有序基础 SKU 与 TrialOverride；不单独维护运营商品目录 |
| 每类页面生效指针 | 主键 scope＋page_type，config_id 可空，revision | 用唯一一行指向当前配置；列表 enabled 由指针派生，避免多个布尔状态漂移；引用必须同 scope／page_type |
| 写入结果记录 | scope＋request_id 唯一，操作者、操作类型、规范化 payload hash、最终结果／时间 | 与业务变更同一事务记录结果，同 ID 同 payload 可安全重放，不同 payload 拒绝 |

使用 PostgreSQL 原子语句及现有事务适配；当前 PostgresDatabase.batch 已在真实 PostgreSQL 事务中执行。外部 Apple 查询在事务前完成，不在数据库锁内等待网络。事务内仍检查修订号、目标类型、准入和生效归属，内容与结果一起提交。

同一次替换先完成所有校验再一次提交，不能靠 Admin 连发“关闭旧／开启新”模拟原子操作。保存生效配置的新内容同样不能让 App 读取半份数据。现有通用 app_config 字符串写接口不能成为绕过本模块校验的入口。

若需新增 schema，仅在 apps/workers-api/src/db/postgres/migrations 添加下一顺序的增量迁移，不修改历史冻结迁移。本方案默认新增表，不修改账单、购买链、权益表和既有唯一约束；dev／prod 分别应用。回退新应用版本时保留新表和历史权益映射，关闭展示入口即可，不删除购买事实。此处仅说明兼容／环境／回退影响，没有执行 DDL 或远程迁移。

### 11.4 幂等和 15+15 秒结果核对

1. 前端一次逻辑写入持有稳定 request_id 和原始 payload。请求未确认时禁用冲突操作，15 秒后最多再核对 15 秒。
2. 只有持久化结果可以确认成功或确认未写入。状态查询没找到记录不代表原请求不会迟到提交。
3. 再次尝试先查原请求，仍未知时仅可安全重放同 ID、同 payload；不得换新 ID 或改 payload 绕过未知结果。
4. 修订号不一致返回明确冲突，保留用户输入；替换对象变化时重新确认，不静默覆盖。
5. 30 秒等待结束后保留输入并允许离开，不能无限轮询。前端保留未确认操作标识以便重新进入后核对；迟到回包按请求上下文隔离。
6. 不建设后台任务队列或发布中心。若请求从未提交，重放会完成原逻辑操作；若已经提交，幂等记录返回同一结果。

### 11.5 Flutter 最小变化

- 页面实例分别持有 Page／Modal 配置快照与选择状态；长期订阅控制器继续负责购买监听、恢复和权益，不因页面关闭销毁尚未完成交易。
- 先确定基础或关联目标 Product ID，再统一计算卡片内容、CTA、主价格、辅助周均价和真实摘要；不分别维护容易失配的购买目标／按钮状态。
- 从实际 StoreKit 商品提取正常周期价格、周期、有效介绍性优惠与资格。现有共享模型只直接提供价格及 storeData，需先核对锁定 SDK 能力，必要时增量扩展类型或现有 iOS 桥接；Android 不执行 Apple 调用。
- 价格使用可信原始数值计算，最终才舍入；若现有 double 不足以保持精确口径，补充可精确表示的值，不从本地化字符串反算。
- 按第 6.6 节执行配置 3 秒上限与全流程 15 秒；等待资格不阻塞其他已可买商品。旧固定美元展示退出新页面消费路径，相关既有测试需随本期意图更新。
- 既有顶部提示、Purchase／Restore 互斥、成功页、来源返回及 blocked_action 恢复继续复用。独立试用安全展示和关联切换失效分支都不得自动代用户转成收费。

### 11.6 收入链路增量

沿用现有 verified JWS 实付提取与 transaction_id 去重；新增商品按显式 Product ID 映射事件，不按营销标题或 SKU 名称猜测。保留 sub_success 与 Firebase purchase 的既有职责，先明确计收来源再调整参数；不新增第二条竞争收入管线。

现有 Singular 仅主动购买路径的实现，不被解释为离线续订已全部覆盖。续订／转付费的负责链路及自动采集去重由数据和研发核对后实现。上报失败继续不阻断 Premium，Restore 不计新收入。

### 11.7 开发顺序和验收

1. 目录适配与商品准入：本地夹具先保护 App／组／类型／优惠边界，再在具备权限时只读联调真实数据。

4. Flutter：配置快照、商品读取、主价格与摘要、试用三态、CTA、兜底及返回。
5. 联调：真实购买、历史恢复、收入、旧包边界；分别报告本地、dev、prod 和真机证据。
