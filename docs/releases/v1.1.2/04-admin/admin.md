## 2026-10-13 订单筛选结果金额汇总

订单统计页在筛选区与订单列表之间展示三项汇总：

- **筛选结果订单数**：当前已生效筛选条件命中的全部订单数，包含退款订单，与列表分页总数一致。
- **订单金额合计（USD）**：仅加总未处于 `refunded` 状态订单的 `amount_usd_micros`；已退款订单不计入，也不再次从该合计扣除。
- **退款金额合计（USD）**：单独加总当前筛选结果中 `business_status = refunded` 的订单 USD 金额。

两项金额与列表复用全部筛选条件、通知确认范围、产品和部署环境限制；不受当前页码、每页条数或 XLSX 导出上限影响。筛选草稿点击“查询”后生效，查询、重置和刷新同步更新汇总。请求加载中或失败时不展示旧汇总金额。

汇总直接使用订单保存的 USD 金额快照，以整数微单位求和后统一格式化显示；不混加不同币种的原始金额，不重新取实时汇率，不将该数值表述为 Apple 扣费后到账收入。退款分类沿用列表的当前业务状态；退款撤销恢复原状态后，该订单重新计入未退款金额，未知状态但已有 USD 金额的订单不作为退款排除。退款订单时间仍沿用已有退款完成时间口径。

缺少 USD 金额的记录不参与加总，并按未退款/退款分别提示缺失笔数。某一类全部金额缺失时显示 `--`；该类没有订单时显示 `$0.00`。合法零金额订单正常计入，混合有值/缺值时显示已知金额的合计并保留缺失提示。

### API 增量

`GET /api/v1/admin/billing/transactions` 保留现有 `items / total / page / page_size`，新增 `summary`：

| 字段 | 类型 | 口径 |
|---|---|---|
| `amount_usd_micros` | number 或 null | 不含退款的 USD 微单位合计 |
| `refunded_amount_usd_micros` | number 或 null | 已退款订单的 USD 微单位合计 |
| `missing_amount_count` | number | 未退款订单中缺失 USD 金额的笔数 |
| `missing_refunded_amount_count` | number | 退款订单中缺失 USD 金额的笔数 |

列表和汇总使用同一筛选构造器；原有数量查询扩展为数量及金额聚合，不新增独立网络请求。订单明细、排序、XLSX 导出和 Admin 鉴权保持原契约。无数据库 schema/migration、App API 或 Flutter 变更。

### 页面与编辑

2026-10-15 用户补充：每组配置的页面展示 SKU 最少 1 个、最多 3 个，订阅页与订阅大弹窗均适用。关联试用 SKU 不占展示名额，独立展示的试用 SKU 和一次性商品计入数量。达到 3 个时禁用“增加 SKU”，删减至不足 3 个后恢复；表单拦截超限保存，服务端同时拦截超限新增、保存和生效。已有超限配置仍完整显示供管理员删减，保留编辑、排序与默认项选择，不自动截断或删除。

- 一级菜单“订阅配置”直接进入“订阅页配置”，列表展示配置名称、页面类型、商品 ID、试用关系／独立试用数量、生效状态、时间和编辑入口。Page／Modal 各自最多一个生效，也可全部关闭；状态来自服务端，不做先切开关的乐观更新。
- 新增配置初始一张空 SKU，订阅类型、无默认项、试用切换关闭、关闭延迟 0。表单分基础信息、试用设置、SKU 卡片和统一配置，沿用 Ant Design 和已有后台颜色／滚动容器。列表操作列固定在右侧；窄屏表单切为单列，收起侧栏时仅本页隐藏账号区，避免遮挡编辑内容。
- 编辑先读取服务端详情；失败只显示重试，不创建可编辑假表单。已有配置保留 revision，已生效类型只读；保存不改变生效状态。
- SKU 上下移动携带完整内容、默认项和试用关系。移除默认项后必须重选；改变商品类型／ID 清除不再适用的试用目标但保留文案，需要重新关联或明确解除。解除最后一组关系需确认并关闭切换；关闭切换只隐藏编辑，已保留关系仍占用目标且可解除。
- 三处 CTA 可空、100 字符、仅纯文本；说明可用 {price}，副文案／角标／价格说明／自定义说明长度与服务端一致。未知商品不因目录读取失败被清空；字段错误与汇总同时展示，可定位到对应字段。
- 页面展示 SKU 的“价格展示方式”增加“不展示”；关联试用 SKU 在“试用商品展示名称”上方提供同样的下拉框，分别保存和回显。旧试用关系没有独立设置时继承源 SKU 当前方式；选择“不展示”只隐藏新版 App 对应商品卡片的价格区域，购买区仍按当前 SKU 的说明方式显示。旧版 App 忽略新增隐藏字段，仍按原价格模式展示；协议及平台边界见[服务端合同](../03-data-api/subscription-display-config.md)与[客户端流程](../01-flows/subscription-display.md)。
- 购买按钮上方说明按当前基础或关联试用 SKU 的说明方式二选一：“自定义文本”只显示该 SKU 的自定义说明，留空则无说明；“自动商品说明”显示 App 按真实商品和资格生成的计费摘要。试用资格未知或无资格时保留 App 的中性价格摘要，不展示自定义试用承诺。后台表单提示与此一致。该新规则覆盖原 PRD 1.14 的固定摘要叠加要求；商品卡片的“不展示”选项仍只影响卡片价格区域，具体 App 行为见[客户端流程](../01-flows/subscription-display.md)。

### 商品目录与准入

订阅和一次性目录分别加载、重试与缓存本页面已取得的参考数据；不新增后台商品 CRUD 或跨页面目录缓存。旧请求按类型和加载序号隔离，切换后的迟到结果不恢复已清理 ID。读取失败保留表单和已保存 ID；成功为空显示空范围，不能显示成读取失败。

选择器为整行 Product ID＋Apple 参考名，展示项与试用目标共同去重；关系候选限制同组／周期／等级、源不带免费试用而目标带免费试用。现选值即使读取失败或刷新后失效也保留可见，提示修正，不能静默换商品。

目录返回未准入商品时显示原因，可准备不生效配置；已知未准入的配置不能在列表启用，编辑生效内容也做提示，最终仍由服务端校验。真实 Apple 目录缺少凭据时如实展示不可用，不使用离线示例替代。价格／资格的 App 展示规则只作运营提示，Flutter 消费的本地实现与待验边界见 [客户端流程](../01-flows/subscription-display.md)。

### 超级管理员商品审批（2026-10-16 dev 已发布）

本功能已随 `dev@06f420a` 发布，运行文件与同提交构建／HTTP 静态资源完成核对，见[发布记录](../05-delivery/VERIFICATION.md#subscription-dynamic-dev-release)。本轮没有使用真实 Admin 登录态执行审批或启用，`cardx.month` 仍待超级管理员确认；部署不等于业务审批已完成。

选择 Apple SKU 后，super_admin 可点击“审核商品准入”（关联目标为“审核试用商品准入”）。弹窗明确展示 dev／prod、Bundle 作用域、Product ID、类型和 Apple 状态；审批人填写当前环境确认的 Singular 收入事件名，并确认 Premium 权益及 1.0.4／1.0.5 无法恢复新 SKU 的边界。operator 没有审批入口，服务端也强制返回 403；客户端角色显示不是授权依据。

审批在服务端重新验证目录并原子注册购买白名单和 billing_product 映射，不要求逐个新 SKU 改环境变量或 SQL。已有冲突映射不会被覆盖。审批成功刷新当前类型目录，保留配置编辑内容；然后另行保存／启用配置。dev 审批不能授权 prod，即使二者都用 Sandbox；prod 需配置自己的 Apple App／目录凭据并重新审批。关闭页面或移除卡片不会撤销历史商品支持。

审批复用下述 request_id／sessionStorage／结果核对机制；提交后返回原页面，结果未知时可以继续核对原请求，不会被审批弹窗遮挡。新客户端需先安装支持动态注册表的版本，旧包不会因服务端审批而自动获得新商品能力。具体数据与回退合同见[动态准入](../03-data-api/subscription-display-config.md)。

### 保存、冲突和结果未知

- 一次保存／生效使用一个 UUID v4 request_id 和不可变请求快照，继续复用现有鉴权、请求关联 ID 和 401 返回登录行为。字段错误保留服务端路径。
- 写入前将原请求、编辑副本和编辑基线存入 sessionStorage，键包含站点、API 基址和管理员 ID；不存 token／Apple 凭据。无法持久化时不发送请求，以免离开后无法安全核对。该存储是未完成操作的恢复记录，不是长期商品缓存。
- 写入最多等待 15 秒，未确认转入最多 15 秒核对；提交／核对中禁用相关写入及冲突离开操作。明确失败恢复操作并保留输入；网络错误／5xx 需要查询原 request_id，查询不到只表示 unknown。
- 核对结束仍未知时允许离开，保留原请求并禁止新写入。重新进入自动核对，不自动重放；手动“核对并重试原操作”必须先查询，再仅重发相同 UUID 和 payload；前置查询与重发共享前 15 秒，后续核对最多 15 秒，不能叠加出新的完整等待窗口。登录失效或重放受拒不能被当作原操作已失败，原记录继续保留。
- 迟到写入结果、卸载后的响应及已被新加载替代的数据不能覆盖当前状态。成功后按服务端重新加载列表；冲突展示明确提示，载入最新内容前确认放弃本地输入。
- 返回、取消、切换菜单或退出登录时，有未保存编辑弹出放弃确认；浏览器刷新／关闭用 beforeunload 提醒。超时仍未知时可离开，操作快照留待同账号核对；sessionStorage 随标签页生命周期，不提供跨设备草稿同步。
