A set card list tells you which physical cards belong to an expansion. It does not tell you what the copy in your hand is worth. Start with the [official Pokemon TCG card database](https://www.pokemon.com/us/pokemon-tcg/pokemon-cards/) to check the set and collector number. Then search Card AI for the matching card record and inspect any available price.

On October 29, 2026, Card AI's public catalog returned these set records. The codes are search aids, not official checklist totals or a promise that every printing has a published price.

## Prismatic Evolutions card list and printings

Search for the PRE set code and the number printed on the card, then compare the artwork and finish. A search for the Prismatic Evolutions Premium Figure Collection asks about a sealed product with promo cards and packs. Its [official product description](https://www.pokemon.com/uk/pokemon-tcg/product-gallery/scarlet-violet-prismatic-evolutions-premium-figure-collection) identifies the contents; Card AI's single-card prices do not value the unopened collection.

## White Flare card list

The public catalog returned an English White Flare set under WHT and a separate Japanese White Flare record under SV11W. Select the language and set that match the physical card. The [official White Flare page](https://www.pokemon.com/us/pokemon-tcg/scarlet-violet-white-flare) also distinguishes this expansion from Black Bolt. A Unova Poster Collection box contains packs from both expansions, so its name alone does not identify a single card's set or price.

## Surging Sparks card list

Search SSP with the collector number instead of using a character name alone. The [official Surging Sparks guide](https://www.pokemon.com/us/features/pokemon-tcg-scarlet-violet-surging-sparks-top-competitive-cards) shows that the expansion includes several featured cards. The set code and number help separate one printing from another before you check a price.

## Paldean Fates card list

The [official Paldean Fates checklist](https://www.pokemon.com/static-assets/content-assets/cms2/pdf/trading-card-game/checklist/paf_web_cardlist_en.pdf) lists multiple Mew ex entries. Search the PAF set and the printed collector number, then confirm the artwork. Do not use the price of a Mew ex from a different set, such as the [30th Celebration example](/blog/pokemon-tcg-30th-celebration-card-prices), for a Paldean Fates copy.

## Shrouded Fable card list

Use the SFA set code and collector number to find the matching card. The [official Shrouded Fable set page](https://www.pokemon.com/us/pokemon-tcg/scarlet-violet-shrouded-fable) describes the expansion and its products. A Shrouded Fable booster bundle is a sealed pack product; it is not a single-card record or a value for the cards inside unopened packs.

## From a card list to an available price

In Card AI, scan the physical card or search by set and number. Review the suggested record, language, artwork and finish. For a raw copy, enter its condition. For an already graded slab, enter the company and grade shown on its label. Then use the [card price checker](/card-price-checker) to see the selected record's available published price and history. A missing price stays missing; another card's price is not a substitute.
