Use this English Phantasmal Flames card list to match the collector number before comparing a price. Numbered entries follow the [official Pokemon Phantasmal Flames checklist](https://tcg.pokemon.com/en-us/galleries/phantasmal-flames/). The price column is a separate Card AI catalog snapshot retrieved November 5, 2026.

## PFL, card number and artwork come first

Card AI lists the expansion as ME02: Phantasmal Flames with the code PFL. Mega Charizard X ex appears at several numbers, including 013/094, 109/094, 125/094 and 130/094. Check the full number and artwork rather than choosing the highest displayed price for the same name.

## Mega Charizard X ex is not one interchangeable card

The [Mega Charizard X ex printing guide](/blog/mega-charizard-x-ex-card-value) compares those four PFL records. The catalog's sample for one number does not apply to every Mega Charizard X ex, another language, or a graded slab. Check the price's date and the confirmed card state in the app before using it as a reference.

Code cards for a Booster Pack or Build & Battle Box are not numbered cards from this checklist. Unnumbered promos and sealed products also remain outside this table. This avoids turning catalog extras into claims about the official set size.

## From checklist to collection

Find the number here, inspect the [official artwork](https://tcg.pokemon.com/en-us/galleries/phantasmal-flames/), then scan or search in Card AI. Use [candidate review](/pokemon-card-scanner) to confirm the printing and finish, choose raw condition or an existing slab grade, and save the holding only after that check.

The public table is a dated reference. It does not quote a guaranteed sale price or predict a grade. See the [card price checker](/card-price-checker) for the pricing workflow and [raw versus graded values](/blog/raw-vs-graded-card-values) for the distinction between card states.
