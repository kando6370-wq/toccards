An Ivysaur card's value depends on the printing, not only the Pokemon name. The English 151 cards 002/165 and 167/165 differ from Base Set 030/102. Within Base Set, an edition and catalog variant can matter even when the number is the same.

The catalog uses the last row's finish field to identify its edition. It is not a label for every shadowless Ivysaur. The table does not enumerate every Base Set edition, language or finish. None of these samples specifies raw condition or slab grade. They are dated published references, not offers, completed-sale records or guaranteed resale values.

## Read more than 030/102

For a Base Set copy, check the edition marking, printed layout, language and matching catalog variant. A number alone cannot tell you to use the 1st Edition reference. If you cannot confirm the edition, keep that uncertainty visible instead of choosing the higher-priced result.

For a 151 copy, retain the numerator and denominator. The catalog numbers 002/165 and 167/165 refer to different records with different artwork. Do not use a card's evolution relationship as a reason to borrow a price from Bulbasaur or Venusaur.
