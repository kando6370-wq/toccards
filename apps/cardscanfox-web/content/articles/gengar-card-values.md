## Which Gengar card do you have?

A search for “Gengar Pokémon card” can lead to several different cards. Start with the complete collector number, then match the set, language and finish. A Fossil holo, a Fusion Strike VMAX and a Lost Origin Trainer Gallery card need separate price comparisons.

Use the records below to identify a printing. Open its detail page for the available price, source and observation date. These are selected examples from our catalog, not a ranking of every Gengar card.

Check the edition stamp on your card before using that amount for an Unlimited copy. A shared character or similar artwork does not make those editions interchangeable.

## Gengar VMAX: 157/264 or 271/264?

Fusion Strike includes more than one Gengar VMAX record. Match the number and artwork before comparing the price:

- [Gengar VMAX 157/264](/cards/253371): the regular numbered VMAX printing in the selected catalog records.
- [Gengar VMAX 271/264](/cards/253266): cataloged as Alternate Art Secret, with a number above the set denominator.

If a search result says only “Gengar VMAX,” it has not identified which of these cards you own. A price for 271/264 should not be used for 157/264. Check the language too: a Japanese printing needs its own matching record.

## Is the Gengar full-art card TG06/TG30?

[Gengar TG06/TG30](/cards/284266) belongs to the Lost Origin Trainer Gallery. Keep both letters in the number when searching. “Full art” is often a broad search description; it does not identify the set or collector number by itself. Check the pictured artwork and the TG prefix rather than selecting the first Gengar image that looks familiar.

## How to check a Gengar card’s value

1. Read the name, set and full collector number on your copy.
2. Open the matching record and compare the artwork, language, edition and finish.
3. Read the selected price source, raw condition or existing slab grade, currency and observation date.
4. If a matching reference is unavailable, keep it unavailable. A different printing’s price is not a substitute.

A reference for a raw Near Mint copy is not a quote for a worn card or a PSA-graded slab. Use the [Pokémon card condition guide](/blog/pokemon-card-condition-guide) and [raw vs graded value guide](/blog/raw-vs-graded-card-values) to keep those comparisons separate.
