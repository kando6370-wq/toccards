## What is my Mega Rayquaza ex card worth?

Use the record matching your copy rather than one price for the character:

1. Match the expansion and full collector number, including the number after the slash.
2. Check the language, artwork and finish against the card image and details.
3. Read the published price source, currency and observation date. Available references can have different dates.
4. Compare raw condition with raw condition. For an existing slab, select the matching grading company and grade when that series is available.
5. Use the available 30-day trend to understand the selected series. Missing days do not mean a zero value.

A price reference is not an authentication result, an assigned grade or a guaranteed sale offer. A scan can help locate a likely catalog match; you still need to confirm which printing you hold.

## Raw cards, graded copies and code cards

A code card for a collection or a box is a different object from the physical Pokémon card. Do not select a result solely because its product name contains “Mega Rayquaza.” The table above links to numbered physical-card records.

Raw and graded prices also describe different objects. A high-grade slab amount cannot be applied directly to a loose card. Read [how raw and graded values differ](/blog/raw-vs-graded-card-values) before comparing the two.
