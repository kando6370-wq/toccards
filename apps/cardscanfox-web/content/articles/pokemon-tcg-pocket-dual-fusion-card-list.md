## Dual Fusion is a Pokémon TCG Pocket set

The Dual Fusion card list is for **Pokémon TCG Pocket**, the digital card game. The C1 release was published on October 29, 2026. A public database currently lists 217 cards. Treat that number as a database count checked on the source page, not as an official Pokémon checklist total.

The official Pokémon announcement introduces dual-type cards in Pocket. Use the set page to check collection numbers, card names, rarities and pack availability. This page does not replace a physical Pokémon TCG expansion checklist.

## What the public card list contains

The public list groups cards by collection number and separates the Mega Mewtwo X and Pikachu packs. Keep the numbered cards and secret cards in separate sections when you maintain a checklist.

| Field | Use it for |
| --- | --- |
| Collection number | Find the card in the C1 list |
| Card name | Confirm the Pokémon or Trainer record |
| Rarity | Filter collection goals |
| Pack | Check the reported pack relationship |
| Game | Keep Pokémon TCG Pocket separate from physical Pokémon TCG |

A database row helps you look up a card. It does not prove that every account has pulled the card.

## Do not mix Pocket with physical Pokémon TCG

If you need a physical Pokémon TCG card, start with the game and expansion name before you search. For Pocket, keep **C1** and the pack name in your query. For physical cards, use the [Pokémon TCG set card list guide](/blog/pokemon-tcg-set-card-lists).

The same Pokémon name can appear in both products. Confirm the game, set code and collection number before you use a card record or price reference.
