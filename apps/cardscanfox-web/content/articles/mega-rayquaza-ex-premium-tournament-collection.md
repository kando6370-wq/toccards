## Release date and product purpose

The Pokémon TCG Mega Rayquaza ex Premium Tournament Collection is scheduled to launch on February 12, 2027. It is a tournament-ready collection with a Mega Rayquaza ex foil promo, accessories and eight booster packs.

## Official contents checklist

| Included item | Quantity or detail |
| --- | --- |
| Mega Rayquaza ex | 1 foil promo card |
| Additional promo cards | 3 foil promos featuring Zinnia’s Trust, Adventure Lantern and Mega Rayquaza Cap |
| Legendary Summit Stadium | 2 cards that form one Stadium |
| Dragon Shield sleeves | 65 sleeves in a thematic box |
| Deck box | 1 Dragon Shield deck box |
| Pokémon coin | 1 plastic coin |
| Booster packs | 8 Pokémon TCG booster packs |
| Pokémon TCG Live code | 1 code card |

These are the contents listed on the official product page. Keep the promo cards and sealed-product contents separate from prices for individual Mega Rayquaza ex printings.

## Product contents and card value are different tasks

This page describes a sealed product and its included cards. It does not set a value for every Mega Rayquaza ex printing. Use the [Mega Rayquaza ex card values guide](/blog/mega-rayquaza-ex-card-values) when you need to identify a single card and compare its dated price context.

A sealed collection can contain cards that have their own catalog records. The product name alone does not identify the condition, language or price series of a single card.
