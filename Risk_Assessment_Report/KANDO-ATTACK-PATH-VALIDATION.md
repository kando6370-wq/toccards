# Kando 攻击路径验证

本文件验证攻击路径与源码、版本和测试计划之间的关联。未执行攻击复现；“验证”不表示路径已在生产成功利用。

## AP-001 构建供应链篡改

旧pnpm或存在公告命中的依赖处理恶意包，进而影响构建环境和制品完整性。版本条件已验证；未执行恶意包PoC。缓解为pnpm11.28.10、依赖升级、冻结安装和audit 0。

## AP-002 Android TLS中间人

受影响Dart版本在Android或桌面`dart:io`使用可推导私钥的eMudhra中间CA链时可能遭MITM。版本与平台条件已验证；未进行网络劫持。缓解为Flutter3.47.9/Dart3.13.7和受控真机TLS回归。

## AP-003 Admin权限提升

若任一Admin路由遗漏角色校验，普通会话可能执行高权限操作。当前仅为理论路径，需在Linux dev执行全路由角色矩阵与审计核对。
